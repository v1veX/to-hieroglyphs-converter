# Конвертер в иероглифы

## Описание

Конвертер для замены символов русского алфавита на визуально похожие китайские (и японские) иероглифы. Буква А станет иероглифом 丹, Б - 石 и так далее. А слово ПРИВЕТ станет 冂尸仈丑仨丅.

Приложение позволяет в один клик сохранить результат конвертации в буфер обмена, хранит историю из 5 последних конвертаций, а также имеет темную и светлую темы.
